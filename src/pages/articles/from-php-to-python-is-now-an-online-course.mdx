## Why an online course?

The book format worked well, but I got feedback from readers who saw some limitations:

- **Not so mobile friendly**: reading a PDF on a phone isn't ideal. I managed to create an ePub version, but this format is still very hard to make right. Some readers struggled with it depending on the device they used.
- **Hard to search**: while PDFs have a search function, it's not as smooth as searching through a website with a proper search engine. 
- **Hard to copy and paste**: sometimes readers wanted to copy code snippets or sections of text, but PDF formatting could get in the way.

I also didn't feel as free as I could be with a static book. Fixing mistakes or typos here and there would require uploading new PDF/ePub versions and ask my readers to download them.

It's now mobile friendly, searchable, easy to copy and paste from, and I can push updates instantly. Also, my readers can send me feedback directly through the platform, making it easier to improve the content over time.

Users can also choose their own syntax highlighting theme for both languages.

The core philosophy remains the same: **take your existing PHP knowledge and map it directly to Python.** I don't want you to waste time on things that are obvious. We focus on the differences and similarities between the two languages.

## What's covered?

The course covers everything from syntax basics to advanced topics:

- Core concepts
- Python-specific features: decorators, context managers, comprehensions
- Practical skills: testing, linting, logging, building a CLI app
- Packaging: the course now promotes [uv](https://docs.astral.sh/uv/) to install dependencies and publish packages to PyPI

- Concurrency (threading, multiprocessing, async)

All of this with **side-by-side PHP and Python code comparisons**.

The course now covers **PHP 8.5** and **Python 3.14**.
